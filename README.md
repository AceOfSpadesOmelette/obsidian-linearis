# Linearis

Source line numbers beside a note, in editing and in reading view. The gutter can sit on the left, on the right, or be turned off. It works on desktop and mobile.

Numbers follow the note’s Markdown source. In the editor, every source line is numbered, including blank lines. A wrapped line keeps a single number on its first row. In reading view, each rendered block shows the source line where that block starts. A table that spans source lines 133–137 shows `133`, then the next block.

The gutter stays on the outer edge of the pane and leaves a thin margin so the note never sits under the numbers.

## Settings

Open **Settings → Linearis**.

| Setting | What it does |
| --- | --- |
| Editing mode | Left, right, or off while editing |
| Reading mode | Left, right, or off while reading |

Under **Backup**, **Export settings** and **Import settings** save or restore that configuration as `linearis-settings.json`.

## Commands

- **Cycle editing placement (left / right / off)**
- **Cycle reading placement (left / right / off)**
- **Set editing placement: left**, **right**, or **off**
- **Set reading placement: left**, **right**, or **off**
